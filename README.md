# FuriPop — X 日文假名助手 v0.2.4

優先完成 X 的日文讀音；YouTube 字幕覆蓋層尚未實作。保留零破版、只深度適配 X／YouTube 的產品方向。

## v0.2.4：中文主文夾日文引文

- 修正「中文文章只要含一小句假名，就把整篇當日文」的誤判。加入隨附 TinyLD 1.3.4 light（約 69 KB）的本機中日文訊號比較；中文主體或中文／日文訊號接近的文章，保守略過自動標音。即使 X 誤標 lang=ja，仍檢查主體內容。
- 圖中「24（+2）歲，曾經是個學生……這個一定有（*やりますねぇ）……壓力也Max捏」已加入核心與真實 MV3 通道回歸測試，分別驗證無語言標記、ja、zh 三種情況都不替中文標音。一般日文、名字、日文引用中文的句子繼續驗證。
- 沒有新增權限、API 或外部服務。TinyLD 授權與來源位於 vendor/tinyld/；只包裝原始 browser ESM export 為可供 content script 使用的全域物件，模型內容未修改。
- 模型分數不是正確率保證。短句、中日混合名字、接近的語境仍可能誤判；目前中文主體採整篇略過，不另外自動標註內嵌日文引文。明確指定的自訂詞典是例外。
- 延續 v0.2.3 的更新提示：重載擴充功能後請重新整理 X。已加入 tests/extension-lifecycle.cjs，驗證舊分頁失效提示與 F5 後恢復；核心測試仍用 node tests/tokenizer.cjs。

## v0.2.2：避免中文誤標與罕見字定位

- 先讀推文／文字區塊的 lang 標記：ja 允許分析，zh／ko 不自動套用日文讀音；X 介面的 html lang 不作為推文語言依據。
- 沒有明確語言標記時，以是否含假名作保守提示。沒有假名的純漢字不自動標音，避免把中文或未知人名硬讀成日文。這是啟發式判斷，無標記的中日混合句仍可能誤判，X 本身的語言標記也可能不正確。
- 自訂詞典是明確指定讀音的例外：即使句子未被判作日文，也只標使用者設定的完整詞，不連帶標句子中的其他中文。
- 滑鼠命中改以 Unicode 字素叢集定位，避免拆開「𠮷」等補充平面漢字或異體字選擇符。這修正定位，不會憑空替詞典補上未知人名讀音。
- 已測中文推文／含日文名字的中文推文略過、中文 UI 上的日文推文、無語言標記的日文、純漢字保守略過、𠮷田 自訂讀音及反白判定。使用隔離瀏覽器的模擬 X DOM 驗證，仍待真實動態牆驗收。

## v0.2.1：人名讀音修正

- 新增 X 帳號顯示名稱（User-Name / UserName）懸停，保留名字原有連結。原先這些區域不在支援範圍，因此「沒顯示」不一定是缺詞。
- 點擴充功能面板的「自訂名字與讀音」，新增完整名字與假名。自訂詞以最長詞優先，覆蓋一般分詞；片假名會轉平假名。可修改、刪除，同步所有 X 分頁，舊的讀音快取會立即失效。
- 最多 100 詞、約 6 KB，存於 chrome.storage.sync。沒有新增權限。相同文字會在所有語境套用相同指定讀音，請盡量用完整名字避免影響一般詞。
- 不會自動查證或猜測缺詞人名；未新增的人名仍可能被分割、誤讀。純假名名字不另顯示重複讀音。修改後移開滑鼠再懸停即可使用；首次升級請重新載入擴充功能並重新整理 X。
- 已在隔離瀏覽器的模擬 X DOM 測試真實 MV3 通道、名字連結懸停、詞典新增／編輯／刪除與快取更新，尚待實際 X 頁面驗收。

## v0.2.0 修正

舊版只會匹配內建百餘詞，因此多數漢字沒有讀音；長句反白只回傳第一個命中詞。
現在使用內附 Kuromoji.js 0.1.2 + IPADIC 詞典分析整段上下文，懸停顯示所在詞的平假名，反白則顯示整句讀音。保留經挑選的次文化詞／繁日異體詞覆寫。

- 推文、回覆與個人簡介可懸停；X 頁面其他唯讀文字可用反白模式。
- 不插入 ruby、不抽換推文 TextNode、不標記已處理節點。以 caret + Range 讀取當下文字、固定浮層顯示；X 更新、SPA 導航、虛擬節點重用後仍按新文字分析。
- 懸停略過連結、按鈕、編輯器；反白可讀包含連結的完整推文。Emoji 與原文維持不變。
- 反白支援滑鼠及鍵盤。浮層會避開視窗邊界；按 Esc、捲動或停用即關閉。非同步過期結果不會重新打開浮層。
- 開關透過 storage.onChanged 同步所有已開啟 X 分頁。
- 完全本機分析，不使用雲端 API、不傳送推文。首次使用才載入詞典，有載入／錯誤提示。

## 安裝／更新

1. 使用 Chrome 116 以上版本，開啟 chrome://extensions/，啟用開發人員模式。
2. 載入未封裝項目，選擇本專案根目錄（manifest.json 所在資料夾）。原有安裝請按重新載入。
3. 重新整理已開啟的 X 分頁；把滑鼠移到「図書館」「新しい」「読みました」等詞，或反白整句。
4. 首次載入需稍候；後續使用共用詞典與有上限的記憶體快取。

權限：storage 儲存開關；offscreen 執行共用 Worker。網域仍僅 x.com / twitter.com。其他網站、YouTube、輸入框尚未注入／支援，舊交接文檔的「任意區域」不代表全網可用。

## 目前架構

content/content.js → runtime message → background.js → engine/offscreen.html → engine/worker.js → vendor/kuromoji/

- Service Worker 只負責建立共用 offscreen document 與轉送請求。
- Offscreen document 管理 Worker 生命週期與逾時；CPU 分詞與詞典解壓均在 Worker。
- Worker 延遲載入單一詞典實例、串行處理請求，快取最多 300 段；分頁另快取 150 段並合併相同未完成請求。
- 單次上限 2000 字，防止巨大反白長文堵塞分析。記憶體快取會在擴充功能／瀏覽器重啟後清除，沒有 IndexedDB 持久快取。
- engine/overrides.js 保留舊版詞庫作為參考；Worker 僅挑選專有詞覆寫，避免「何」「今日」「私」等單字先硬切造成語境誤讀。
- 所有讀音透過 textContent 顯示，沒有把推文當作 HTML 注入。

Kuromoji 的接法依據官方專案：https://github.com/takuyaa/kuromoji.js 。隨附套件及詞典授權見 vendor/kuromoji/LICENSE-2.0.txt 與 NOTICE.md。詞典約 17 MB 壓縮資料，解壓後記憶體用量更高；共用 Worker 避免每個分頁都載一份。

## 驗證與限制

已驗證一般長句、活用、次文化詞、空白／換行、emoji／罕見字的 UTF-16 位置、未知字保留原文；真實 Chrome 驗證懸停、反白、連結保護、Esc 與推文 DOM 不變。隔離 Edge 的 MV3 擴充功能測試已串起完整背景／offscreen／Worker／詞典／內容腳本，並驗證節點重用及跨情境開關同步。

可用 Node.js 18+ 執行 `node tests/tokenizer.cjs` 重跑核心回歸測試，不需 npm install。

這些測試使用本機模擬 X DOM，尚未在登入的真實 X 動態牆手動驗收。X 若改動 tweetText / UserDescription 標記需調整選擇器。單一文字節點以外的詞能映射 Range，但由 X 分割的上下文、換行或 emoji 替代內容仍可能影響詞境。

分詞詞典不能保證人名、新詞、繁體中文句子或多音字讀音正確；沒有可靠讀音時保留原文並提示。漢字懸停以詞為單位，並非將每個漢字強制配一個讀音。不為純假名／英文顯示多餘標音。極長反白浮層可能只顯示可容納部分，請縮短選取段落。

# FuriPop - X (Twitter) 日文假名懸停助手 ✨

專為 **X (Twitter)** 與 **YouTube (ACG/J-POP)** 設計的輕量日文假名助手。

## ⚠️ 已知技術地雷與踩坑紀錄 (Gotchas & Warnings)

1. **推特 SPA 虛擬 DOM**：
   - 遍歷推文子節點時，必須先 `walk(child)` 完成替換，再給父容器加上 `data-furipop-done="true"` 標記。若順序顛倒會導致遍歷中斷。
2. **文字節點抽換**：
   - 遇到 `<a>`（推特 Hashtag、Mention、短網址）與 Emoji 節點時，必須略過或保護，避免推特點擊連結失效。
3. **Chrome 擴充功能重新載入機制**：
   - 修改 `manifest.json` 或 `content.js` 後，必須在 `chrome://extensions/` 點擊重新整理按鈕，並在推特頁面按 `F5` 才能看到最新代碼效果。
